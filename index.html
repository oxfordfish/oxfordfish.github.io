🏎️ F1 Telemetry & Speed Profile Plotter

A Python data pipeline using the FastF1 API to analyze lap telemetry and generate 2D spatial track heatmaps.

  • Lap Telemetry Traces: Side-by-side analysis of Speed, Throttle %, Brake pressure, and Gear usage.
  • 2D Track Heatmaps: Renders circuit layouts using GPS coordinates with a continuous speed colormap (plasma).

⚡ STM32 Custom Breakout & Development Board

In Fabrication / Untested

A custom 2-layer PCB designed around the STM32F103C8T6 microcontroller, featuring on-board power regulation, USB connectivity, SWD debugging, and broken-out bus interfaces.

  • Peripheral Breakout Headers: Dedicated pins for USART, CAN Bus, and I2C (with pull-up resistors) for rapid prototyping.
  • Power & Regulation: On-board LDO regulator (5V to 3.3V) with decoupling networks and USB ESD protection.
  • Debugging & Flashing: Integrated SWD (Serial Wire Debug) header and boot mode configuration switch.
  • Status & Design: Power LED indicator, user-programmable LED, engineered using KiCad 8.0.
